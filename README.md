# PakSeekers

PakSeekers is an exam-preparation platform built with Next.js, TypeScript, Tailwind CSS, and Prisma. The application includes exam browsing, topic practice, and admin content-management routes.

## Development

Requirements: Node.js and a PostgreSQL database.

1. Install dependencies with `npm install`.
2. Set `DATABASE_URL` in `.env` to your PostgreSQL connection string.
3. Start the development server with `npm run dev`.

Run `npm run lint` to check the code and `npm run build` to create a production build.
